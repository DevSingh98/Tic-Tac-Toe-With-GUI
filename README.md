# Tic-Tac-Toe with GUI

This is a Java program that implements a Tic-Tac-Toe game with a modern graphical user interface (GUI) using JavaFX and Java 21.

## Features
- **Modern UI Design**: Contemporary styling with gradients, shadows, and smooth animations
- **Multiple Game Modes**: Player vs Player and Player vs Computer
- **AI Difficulty Levels**: 
  - Easy Mode: Random computer moves for beginners
  - Hard Mode: Minimax algorithm for challenging gameplay
- **Interactive Elements**: Hover effects, visual feedback, and intuitive controls
- **Navigation**: Easy switching between game modes and return to main menu
- **Game Status Display**: Real-time game state and winner announcements

## How to Run
1. Ensure you have Java 21 and JavaFX set up on your system.
2. Clone the repository:
   ```bash
   git clone https://github.com/your-repo/Tic-Tac-Toe-With-GUI.git
   cd Tic-Tac-Toe-With-GUI
   mvn javafx:run
   ```

## Controls
- Click game board squares to make moves
- Use sidebar buttons to switch between game modes
- Toggle AI difficulty when in computer mode
- Restart button to reset the current game
- Main Menu button to return to start screen
